EX280

Red Hat Certified System Administrator in OpenShift exam

Exam Description

The Red Hat Certified System Administrator in OpenShift exam (EX280) tests the knowledge, skills, and ability to create, configure, and manage a cloud application platform using Red Hat OpenShift Container Platform.

By passing this exam, you become a Red Hat Certified System Administrator in OpenShift that also counts towards earning a Red Hat Certified Architect in OpenShift.

Earning a passing score on this exam is a requirement to attain the Red Hat Certified System Administrator in OpenShift certification.

Exam Format

This is a hands-on, practical exam. Rather than answering multiple-choice questions, you are required to perform routine system tasks on a live system to meet specific objective criteria.

Relevant product documentation is provided during the test, but you must complete the tasks without outside assistance.

Exam Delivery

Exam results are reported via email from Red Hat Certification Central. Red Hat does not authorize examiners or training partners to report results to candidates directly. Scores on the exam are usually reported within 3 U.S. business days.

Exam results are reported as total scores. Red Hat does not report performance on individual items, nor will it provide additional information upon request.

Be sure to review the Red Hat Certification Program Guide to ensure you are familiar with all official policies and exam procedures before booking your session.

Target Audience

  • System Administrators who need to support the initial setup, configuration, and ongoing maintenance of an OpenShift cluster, including managing authentication, users, and network security.
  • Site Reliability Engineers responsible for ensuring high service availability by monitoring, assessing cluster health, troubleshooting, and maintaining ongoing cluster operations.
  • Platform Engineers responsible for configuring OpenShift to ensure developer teams have access to self-service tools, application delivery pipelines, and reliable cloud infrastructure.
  • Application Developers working in a DevOps environment who need to deploy applications, configure container resource manifests (YAML, Kustomize, Helm), and expose services on Red Hat OpenShift.
  • Infrastructure Engineers responsible for managing Kubernetes resources, evaluating cluster status, and maintaining the OpenShift platform.

The time limit for this exam is 3.0 hours.

The following objectives outline the tasks you will be expected to perform on the exam. Please note that there are multiple versions of the exam available so you should select the objectives that match the version of the exam you plan to take. You may select the version of the exam you take when you schedule your exam.

Performance Rule

As with all Red Hat performance-based exams, configurations and services must persist and remain functional across the normal lifecycle of the platform without requiring manual intervention to restore or start them.

Recommended Preparation

Candidates for this exam should:

  • Have taken Red Hat System Administration I (RH124) or have comparable experience. Red Hat Certified System Administrator (RHCSA) is strongly recommended but not required.
  • Have taken Red Hat OpenShift Administration I: Containers & Kubernetes (DO180) course or have comparable work experience using OpenShift Container Platform
  • Have taken Red Hat OpenShift Administration II: Operating a Production Kubernetes Cluster (DO280) course or have comparable work experience using OpenShift Container Platform
  • Review the Red Hat Certified System Administrator in OpenShift exam (EX280) objectives
  • Experience with container technology is recommended

Impact Statement

A Red Hat Certified System Administrator or Red Hat Certified Developer has demonstrated the baseline hands-on skills required to independently run production workloads, whether managing enterprise systems or building and deploying containerized applications. Because every Red Hat exam is performance-based, this credential tells an employer the holder has actually done the work, not answered questions about it. Holders of this credential are ready to carry out production responsibilities.
